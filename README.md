# MathPocket 🤖📐

**MathPocket** — это многофункциональный математический Telegram-бот, разработанный на платформе **.NET 8.0**. Он спроектирован как персональный помощник для школьников и студентов, обеспечивающий не только вычисление результатов, но и подробное пошаговое объяснение решений.

---

## 🌟 Основные возможности

### 🏗️ Алгебра и Многочлены
*   **Степени:** Возведение в степень, упрощение выражений с основаниями, сравнение степеней.
*   **Одночлены:** Приведение к стандартному виду, умножение, деление и возведение одночленов в степень.
*   **Многочлены:** Сложение, вычитание, умножение, деление на одночлен и разложение на множители (вынесение общего множителя, группировка).
*   **ФСУ:** Полный набор формул сокращенного умножения для упрощения и разложения.

### 📈 Функции и Графики
*   **Визуализация:** Построение графиков линейных ($y=kx+b$), квадратичных ($y=ax^2$) функций и гипербол ($y=k/x$) с использованием `ScottPlot`.
*   **Анализ:** Определение области определения $D(f)$, множества значений $E(f)$, нулей функции и промежутков монотонности.
*   **Системы уравнений:** Графическое решение систем линейных уравнений.

### 📐 Уравнения и Корни
*   **Квадратные уравнения:** Решение через дискриминант с выводом всех шагов.
*   **Корни:** Упрощение квадратных корней (вынесение множителя из-под знака корня).

### 📊 Статистика
*   **Обработка данных:** Составление вариационных рядов, поиск моды, медианы, наибольшего и наименьшего значений.
*   **Частотный анализ:** Расчет абсолютных и относительных частот, построение таблиц частот.

### 🧮 Универсальный калькулятор
*   Встроенный модуль для вычисления сложных арифметических выражений с соблюдением приоритета операций и подробным описанием каждого шага.

## 🚀 Быстрый старт

### Требования
*   [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

### Локальный запуск
1.  Склонируйте репозиторий.
2.  Установите токен вашего бота (получите у [@BotFather](https://t.me/BotFather)):
    ```bash
    export BOT_TOKEN="your_telegram_bot_token"
    ```
3.  Запустите проект:
    ```bash
    dotnet run
    ```

### Использование через Docker
```bash
docker build -t mathpocket .
docker run -e BOT_TOKEN="your_token" -p 8080:8080 mathpocket
```

## 📁 Структура проекта
*   `Program.cs` — Точка входа, инициализация бота и Health Check сервера.
*   `BotHandler.cs` — Ядро логики обработки сообщений и управления состояниями пользователей.
*   `FunctionCatalog.cs` — Реестр всех доступных математических функций.
*   `UniversalCalculator.cs` — Движок пошагового вычисления выражений.
*   `Poly/`, `Class/` — Модули для работы с многочленами и степенями.
*   `Functions_*.cs` — Реализации конкретных математических разделов.
