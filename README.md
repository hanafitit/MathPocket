# MathPocket

**MathPocket** — это математический Telegram-бот, разработанный на .NET 8.0. Он помогает решать задачи по алгебре, строить графики функций и выполнять статистический анализ данных.

## Основные возможности

*   **Алгебра:** работа со степенями, одночленами и многочленами.
*   **Формулы сокращенного умножения (ФСУ):** разложение на множители, упрощение выражений и решение уравнений.
*   **Функции и графики:** построение графиков линейных, квадратичных функций и гипербол с использованием библиотеки `ScottPlot`.
*   **Системы уравнений:** графическое решение систем линейных уравнений.
*   **Статистика:** построение вариационных рядов, таблиц частот и анализ данных.
*   **Универсальный калькулятор:** пошаговое решение арифметических выражений.

## Переменные окружения (Environment Variables)

Для работы бота необходимо настроить следующие переменные окружения:

*   `BOT_TOKEN` (**обязательно**): Токен вашего Telegram-бота, полученный от [@BotFather](https://t.me/BotFather).
*   `PORT` (опционально): Порт для встроенного HTTP-сервера (используется для Health Check, например, на Heroku или Render). По умолчанию — `8080`.

## Как запустить

### Локально
1. Установите [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Склонируйте репозиторий.
3. Установите токен бота:
   ```bash
   export BOT_TOKEN="ваш_токен_здесь"
   ```
4. Запустите проект:
   ```bash
   dotnet run
   ```

### Через Docker
1. Соберите образ:
   ```bash
   docker build -t mathpocket .
   ```
2. Запустите контейнер:
   ```bash
   docker run -e BOT_TOKEN="ваш_токен_здесь" -p 8080:8080 mathpocket
   ```

## Используемые технологии
*   [.NET 8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
*   [Telegram.Bot](https://github.com/TelegramBots/Telegram.Bot) — библиотека для взаимодействия с Telegram Bot API.
*   [ScottPlot](https://scottplot.net/) — библиотека для визуализации данных и построения графиков.
